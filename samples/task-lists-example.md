# Task Lists

## Simple

- [ ] Write the proposal
- [x] Review the budget
- [ ] Schedule the kickoff meeting

## Nested

- [ ] Launch checklist
  - [x] Draft release notes
  - [x] Tag the release
  - [ ] Announce on socials
    - [ ] Twitter
    - [ ] Blog post

## Mixed with regular list items

- [x] Set up repository
- Regular bullet, not a task
- [ ] Configure CI
  - Regular nested bullet
  - [x] Add lint step
  - [ ] Add test step
